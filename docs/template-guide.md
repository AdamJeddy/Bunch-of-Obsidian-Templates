# Using each template

Create and name a note, insert the template, then fill the listed fields. Filenames here are suggestions for notes in your vault; do not rename the template files themselves. None of these templates needs a community plugin.

| Template | Suggested note name | First steps |
| --- | --- | --- |
| [Daily Note](../Daily%20%26%20Weekly/Daily%20Note%20Template.md) | `2026-11-15` | Choose today's focus; fill tasks and journal. At day's end, set mood and energy (1–5) in Properties. |
| [Weekly Review](../Daily%20%26%20Weekly/Weekly%20Review%20Template.md) | `2026-W46` | Confirm `week` and `week_year`; review daily notes, record wins, and choose next week's focus. |
| [Month](../Monthly%20%26%20Yearly/Month%20Template.md) | `2026-11` | Confirm year/month; set goals and replace the previous/next month link prompts. |
| [Year](../Monthly%20%26%20Yearly/Year%20Template.md) | `2026` | Confirm year; review the linked months, then fill achievements, reflections, and resolutions. |
| [Book](../Books/Book%20Template.md) | `The Dispossessed` | Set author, genre, pages, reading dates, and rating in Properties. Put quotes and takeaways in the body. |
| [Book Table](../Books/Book%20Table%20Template.md) | `The Dispossessed - Quick Notes` | Fill the compact table manually. Use the full Book template if you need queryable book fields. |
| [Book Log](../Books/Book%20log%20Template.md) | `2026 Reading Log` | Set the reading goal in the heading; add book links to the table and update summary numbers manually. |
| [Personal Contact](../People/People%20v1%20Template.md) | `Sam Rivera` | Set birthday/location and aliases in Properties; add how you met, preferences, and interaction notes. |
| [Professional Contact](../People/People%20v2%20Template.md) | `Sam Rivera - Work` | Set occupation/company/location in Properties; fill contact details and professional links in the body. |
| [Goal Setting](../Projects%20%26%20Goals/Goal%20Setting%20Template.md) | `2027 Goals` | Set `timeframe`; choose goals with target dates and schedule quarterly reviews. |
| [Project](../Projects%20%26%20Goals/Project%20Template.md) | `Community Garden` | Set status, priority, deadline, and category; write the objective and break it into milestones and tasks. |
| [Meeting Notes](../Projects%20%26%20Goals/Meeting%20Notes%20Template.md) | `2026-11-02 Garden Planning` | Set meeting date/type and attendees; prepare an agenda and turn discussion into owned action items. |
| [Decision Log](../Projects%20%26%20Goals/Decision%20Log%20Template.md) | `Garden Watering Plan` | Link the parent project, compare options, record the choice and reasoning, then set status and review date. |
| [Project Retrospective](../Projects%20%26%20Goals/Project%20Retrospective%20Template.md) | `2026-11-14 Garden Retrospective` | Link the project, compare intended and actual outcomes, and assign an improvement for next time. |
| [Project Dashboard](../Projects%20%26%20Goals/Project%20Dashboard%20Template.md) | `Project Dashboard` | Add project links and next actions; update review reminders and `last_reviewed` manually. |
| [Habit Tracker](../Habits/Habit%20Tracker%20Template.md) | `2026-11 Habits` | Name the habits and weekly goals; use the grid's mark legend and cross out nonexistent dates. |
| [Job Applications Dashboard](../Career/Job%20Applications%20List%20Template.md) | `Job Search` | Set search status; link individual application notes and maintain pipeline tables/counts. Update `last_reviewed` when reviewing. |
| [Job Application](../Career/Job%20Application%20Tracker%20Template.md) | `Acme - Product Designer` | Set company, role, status, and applied date in Properties; track contacts, interviews, and follow-ups below. |
| [Trip Planner](../Travel/Trip%20Planner%20Template.md) | `Kyoto Trip` | Set destination, dates, status, and currency; fill the itinerary, budget, and packing checklist. |
| [Travel Journal](../Travel/Travel%20Journal%20Template.md) | `2026-11-15 Kyoto` | Set location, trip day, and mood; record highlights, expenses, and tomorrow's plan. Link your trip planner. |
| [Recipe](../Food/Recipe%20Template.md) | `Lentil Soup` | Set cuisine, difficulty, minutes, servings, and rating out of 5; add ingredients, instructions, and the source. |
| [Meal Prep Plan](../Food/Meal%20Prep%20Plan%20Template.md) | `2026-W46 Meals` | Confirm ISO week/year; link recipe notes in the meal plan and list groceries and preparation tasks. |
| [Grocery List](../Food/Grocery%20List%20Template.md) | `2026-11-15 Groceries` | Set store, budget, and currency; add items and tick them off while shopping. Enter the estimated total manually. |
| [Movie / TV Log](../Media/Movie%20TV%20Log%20Template.md) | `Arrival` | Set type/year/genre/watch status and a rating out of 10 in Properties; add a review and viewing log. |
| [Lecture Notes](../Study%20-%20University%20-%20School/Lecture%20Notes%20Template.md) | `Biology - Week 03 - Cells` | Set `subject` to a quoted course link, teaching week, and topic; capture questions and homework. |
| [Study Schedule](../Study%20-%20University%20-%20School/Study%20Schedule%20Template.md) | `Autumn 2026 Study Schedule` | Set semester/start/end dates; link courses and fill a realistic weekly timetable. |
| [University Subject](../Study%20-%20University%20-%20School/University%20Subject%20Template.md) | `Biology 101` | Set semester, professor, and status; add assignment deadlines, resources, and lecture-note links. |

For past or future periods, correct inserted dates to match the note. Core Templates fills today's date, even when the filename contains another date.

For a step-by-step contact setup, see [Using the People templates](people.md), including personal and professional examples and links from meetings.

See the [project workflow](workflows/project-workflow.md) and [completed examples](../examples/README.md) for linked notes in use.
